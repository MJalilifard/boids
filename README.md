# What is Boids? :bird:
Boids is an artificial life algorithm, which simulates the flocking behaviour of birds, and related group motion. 

## Some improvements can be done :arrow_up:
- Far neighbors have more influence on the separation vector which is not realistic.
- Use reflective boundaries instead of periodic. However I'm not sure it's an improvemnt.
- Create animation for agents's movement. :white_check_mark: 
## Bugs :bug:
